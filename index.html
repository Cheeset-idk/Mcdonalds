Press Enter on a menu command line (like !New prop) to open it. Full list in the Commands tab.

Name: wordsThat character talks and the words show as a caption. Narrator: words shows a caption with no speaker.
Plain textShows in the top left corner for a few seconds, then fades.
#Location Gus, MabelEveryone walks off, the camera rises to the sky, drops into the new location, and only the named characters walk on. #Location @a brings everyone. An unknown location name is created automatically with default scenery.
!Expression: sad Gus, MabelSets expressions: neutral, happy, sad, mad, surprised, scared, sleepy. Use @a for everyone.
!New propOpens a drawing menu. Draw, name it, save it.

!Delete prop: PieRemoves the prop from the scene. Saved drawings are deleted from the prop list menu.
